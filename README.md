# 🏛️ Chichén Itzá App

Aplicativo educativo desenvolvido para um **trabalho escolar**, com o objetivo de apresentar o tema de uma forma criativa e interativa.

## 📖 Sobre o projeto

O projeto surgiu a partir de uma atividade proposta pelo professor, na qual os alunos deveriam se dividir em grupos e criar algo criativo sobre cientistas importantes para a sociedade.

Como nosso grupo ficou formado por apenas duas pessoas, decidimos fugir do formato tradicional e desenvolver um **aplicativo**.

O aplicativo reúne informações sobre **Chichén Itzá**, sua história, cultura e arquitetura, além de um **quiz interativo** para testar os conhecimentos do usuário.

## 🤖 Desenvolvimento

Durante o desenvolvimento, foram utilizadas ferramentas de **Inteligência Artificial como auxílio**, principalmente para programação, resolução de problemas, organização de ideias e outras etapas do projeto.

O aplicativo também passou por testes e ajustes antes de chegar à versão final.

## 📱 Conteúdo

* História e informações sobre Chichén Itzá
* Cultura e arquitetura maia
* Curiosidades
* Informações sobre seus principais monumentos
* Quiz interativo

## 📌 Status
